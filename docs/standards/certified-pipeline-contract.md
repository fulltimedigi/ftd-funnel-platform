# العقد الرسمي — خط الأنابيب المُصدَّق (BINDING — يُذكر في كل decision-record بعده)

> يُثبَّت أولًا. كل عمل لاحق (المُصرِّف، النواة، النشر، التشغيل، العرض) يُقاس على هذا العقد.

## السلسلة
```
المخّ يقترح البنية
  · المُصرِّف البنيوي (Structural Compiler) يرمّز المسارات
  · النواة (Kernel) تُقيّم وتُصدِّق
  · الناشر (Publisher) يقبل CertifiedArtifact فقط
  · التشغيل (Runtime) يُنتج SelectionResult فقط
  · العارض (Renderer) يعرض SelectionResult فقط
```

## القاعدة الحاكمة — المراجع مبهمة خارج النواة
`refs` (مراجع القيود/المطابقة) **مبهمة خارج النواة** — **لا يفسّرها** المُصرِّف ولا التشغيل ولا العارض. **أي `ref`
يُفهَم أو يُقارَن خارج النواة = مُطابِق ثانٍ مقنَّع** (نفس عيب الباب الخلفي). المخّ **يتوقف عن حساب المطابقة نهائيًا**.

## الأنواع الثلاثة (قبل أي كود)
```
AuthoringIR          ← مخرَج المخّ + المُصرِّف البنيوي (حالات · مسارات · مراجع قيود مبهمة). لا SKU مختارة.
CertificationInput   ← ما تستهلكه النواة
CertifiedArtifact    ← مُنشئه داخل النواة فقط (Symbol-sealed). publish(artifact: CertifiedArtifact) لا publish(config)
```
- **Structural Compiler:** شجرة ⟶ حالات/مسارات/مراجع **فقط**. **ممنوع بنيويًا** أن يُنتج: SKU مختارة · `match_state`
  · proof · scores · مجموعة مرشحين.
- **Kernel Certifier:** النواة **وحدها** تُقيّم الحالات، تختار المرشحين، وتُنتج الصفوف والإثباتات.

## Kernel Authoring Oracle — دالة واحدة فعلًا (لا غلاف)
دالة واحدة `evaluateConstraints(state, catalog, policy)` يستخدمها: بناء الشجرة · التصديق · التشغيل. الاختلاف في
**نمط الاستدعاء فقط** (التأليف يطلب كل المرشحين؛ التشغيل يطلب نتيجة جلسة). **أي نسخ للـpredicates بين التأليف
والتشغيل = مُطابِق ثانٍ.** (غلاف رفيع فوق النواة = predicates متكررة = مُطابِق ثانٍ راجع من الباب الخلفي.)

## نُسختا الكتالوج (ق17 — بنيوي مقابل تشغيلي)
- `structural_catalog_version` — هوية · محتوى · خصائص ملاءمة · إضافة/حذف SKU · عبور نطاق سعر قراري ⇒ **STALE +
  إعادة بناء**.
- `operational_snapshot_version` — توافر · سعر داخل النطاق نفسه · شحن ⇒ **طبقة تشغيلية**: تُعرض بصدق (غير المتاح
  موسوم بلا CTA فعّال — ق14). **رفض artifact لأن catalog_version تغيّر = خطأ (يخالف ق17): stale كل ما نفد منتج.**

## التعهّد المسبق (يُكتب الآن قبل رؤية أي رقم)
**الذهب مجمَّد بهاش ولا يُعاد توقيعه أبدًا.** عندما تتحرك الأرقام بعد الأوراكل: **تُعرض كما هي**، ثم نقرر — قبولها
كحقيقة جديدة أو إيجاد عيب حقيقي. **ممنوع تعديل المسطرة أو أي assertion أو الذهب لتحسين المظهر.** الفرق يُعرَض
**قبل** أي معالجة.

## تعريف الإنجاز (لهذا العقد)
- الادّعاء لا يُقبل إلا بأثر من **مسار الخدمة الفعليّ** (`createProductionPipeline()`), لا من مسار الاختبار.
- **ممنوع أي verifier أمان يرجّع boolean فقط** — يرجّع `VerificationReport`، و`ok` تُشتق في مكتبة مستقلة.
- أي طبقة منطق تُبنى **تُضاف فورًا** لقائمة الوصول الإلزامية (bundle-reachability). وحدة لا يستوردها إلا الاختبار
  = **بناء غير مكتمل، لا إنجاز.**

## مؤجَّل بقرار (مسجَّل)
تنفيذ النواة لشجرة أصلًا · Shadow mode · webhooks الانجراف · **إعادة الاختيار التشغيلي وقت التشغيل** (يتطلب شهادة
للـSKU البديلة على نفس المسار — سؤال تصديق جديد) · تحسينات العرض.
